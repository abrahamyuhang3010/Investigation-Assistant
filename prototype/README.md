# 研判助手 · 全量前端交互原型

基准日期：2026-09-19；Figma 案件流程同步：2026-09-20。依据现有PRD、D01–D11技术资料和Figma规范完成的本地可运行原型。

**34个页面/视图、67项功能映射、22条跨页面业务链路。所有数据为合成，禁止录入真实案件或身份信息。**

## 启动与打开

```sh
./start.sh
```

浏览器打开 **http://127.0.0.1:4186**。服务器只监听本机，未部署到公网。如果服务已经运行，直接访问即可，不要重复启动。端口占用时先确认占用进程，不终止其他项目的服务。可指定其他端口：

```sh
PORT=4187 ./start.sh
```

默认进入全域态势地图工作台（`#/PG02`），顶部导航根据当前路由高亮；超级搜索和两条预置合成会话仍保留。顶部“功能总览”可切换**页面 / 功能点 / 交互链路**，用于逐项评审；普通业务操作走左侧导航、工作台和页面按钮。深链例：`http://127.0.0.1:4186/#/PG20`。

无需安装前端运行时依赖；需要Node.js，启动脚本优先使用PATH中的Node，再尝试本机Codex bundled Node。不能直接双击HTML：ES模块需要HTTP服务。

## 全域态势 Map-first 工作台

- 地图占满内容区域，统计、筛选、AI洞察、Inspector、图例、控制器悬浮于地图之上；不再使用三栏地图卡片。
- 复用现有浅深语义tokens、`ui.js`组件/图标接口及本地ECharts；工程为原生ES modules，不安装React或另一套UI库。
- 真实南阳市边界位于 `assets/maps/411300.json`，校验完整13区县、唯一adcode与有效多边形。来源和导入处理详见 `assets/maps/README.md`。
- 单击地图/列表只选中并更新Inspector和AI；双击地图或“进入辖区”才下钻。县级统计与演示街道可用，县/街道真实边界未接入时显示明确提示，绝不画虚构多边形。
- `globalScope`统一查询条件；`getSituationSnapshot()`提供按adcode索引的RegionMetric。市县总数严格相加一致；选中不改变全域总量；缩放/拖动不改变业务范围。
- `ResizeObserver`测量真实Overlay尺寸，折叠与窗口变化触发地图safe area重排；保留选中与视觉视口。
- 热力开关可用，警力和重点场所图层显示“待数据”并禁用。AI洞察为模板化合成统计，未接真实模型。
- Loading/Empty/Error/Permission/Stale/Partial可由现有状态演示入口测试；地图请求错误可独立重试。
- 核心文件：`src/global-situation.js`、`src/global-situation-panels.js`、`src/global-situation-data.js`、`src/global-situation.css`、`src/situation-map.js`。
- 验收命令：`node tests/global-situation.mjs`。检查地图真实点击/双击、联动、数据守恒、异常恢复、1440/1600/1920和窄屏/深色主题。

## 演示控制

- **推进任务：** 默认手动。打开“演示控制”，选择场景并保存；到执行详情点“推进一步模拟事件”。也可打开自动推进，约每3秒推进一步。
- **任务场景：** `success`正常、`permission`授权阻断、`failure`工具失败、`partial`部分结果、`empty`未检出记录。新建复杂任务、确认计划后可完整观察分支。
- **页面状态：** 顶部状态选择器独立预览正常、加载中、空状态、加载失败、无权限、数据过期；这不是后台业务状态的修改入口。
- **角色与组织：** 右上头像切换研判人员、业务负责人、审批人员、平台管理员、安全审计人员以及演示组织。切换前看影响提示；平台管理员不能默认读业务正文。
- **主题与窄屏：** 顶部日/月图标切浅深主题。小于1280px右侧空间变抽屉，手机宽度保留业务导航和表单。
- **重置：** 演示控制中的重置会清除当前本地模拟修改，恢复种子数据；先导出要保留的模拟成果。
- **异常提示：** 查看失败原因后重试；停止任务需要等停止确认；审批通过需申请人显式恢复，不会自动继续。

## 推荐的完整演示路径

### 1. 复杂研判到报告

1. 新建搜索，输入针对“演示对象甲”的轨迹核验需求，发送。
2. 填写澄清卡中的对象、时间、类型、来源并核对稳定标识。
3. 查看/调整计划，点击确认执行。
4. 执行详情手动推进，或先开启自动推进；查看每个动作的工具版本和输出摘要。
5. 查看人员流结果，核验冲突、实体及原始来源，进入时间线或关系导图。
6. 生成报告，核验来源/数据缺口等检查项，编辑保存版本。
7. 进入复核与导出；提交后换业务负责人且使用不同演示身份复核，禁止自审。
8. 填写用途、确认脱敏与范围，下载TXT/JSON。成果可关联到案件，关联的是冻结版本。

### 2. 资金与只读数据库分析

- 资金流：分析入口 → 计划 → 执行 → 账户/日期筛选 → 交易/来源 → 账户A的1跳或2跳路径 → 资金报告；交易可导出CSV。未知账户返回空，不会导出其他账户数据。
- 数据库问答：问题和口径 → 固定SELECT模板 → 本地只读检查 → 合成分类结果与总量核验 → 收藏/CSV/继续分析。任意SQL不接真实数据库。

### 3. 授权、故障与安全恢复

- `permission` → 新任务执行遇阻 → 我的申请 → 提交范围/用途 → 切审批人员审批 → 切回申请人 → 恢复原任务。
- `failure` → 动作失败 → 局部重试，保留已完成动作；`partial` → 部分成功与缺口披露。
- 执行中安全暂停 → 刷新 → 检查并恢复；或停止 → 停止中锁发送 → 确认终止后允许新任务。
- 模拟断线 → 写草稿/刷新 → 重连，恢复快照与阅读位置，不重放工具动作。

### 4. 因案、因事和串并

- 因案列表 → 案件详情 → 带案件发起研判 → 报告 → 关联成果版本 → 后续修改不改变已关联版本。
- 因事列表 → 三步向导（基本信息/1–5实体/工具频次）→ 只创建不执行 → 确认采集 → 确认计划 → 执行/产物/笔记。
- 串并候选 → 人工核对支持依据与反证 → 填写意见 → 负责人复核 → 导出核验意见；没有正式合并操作。

### 5. 工具、配置、经验和Skills

- 平台管理员：工具契约编辑 → 本地检查 → 发布 → 禁用影响提示/回滚；回滚产生新版本，历史执行仍引用旧版本。
- Agent配置：编辑执行约束和工具集 → 检查 → 发布/回滚。
- 业务负责人：经验候选 → 模拟评测 → 发布 → 下线。
- Skills：完整设计编辑/检查/发布/停用/历史预览；**运行按钮禁用、真实调用为0**，遵照D11首期范围。

## 文件结构

```text
prototype/
  index.html              页面入口及弹窗/提示容器
  server.mjs              本机静态服务、CSP与禁止目录穿越
  start.sh                启动脚本
  src/requirements.js     34页、67功能、22链路元数据
  src/state.js            合成数据、任务状态、存储与映射
  src/ui.js               表单/按钮/图标/转义组件
  src/entity-node.js      共享实体节点与画布（配套entity-node.css）
  src/case-workflow.js    案件五步工作流（配套case-workflow.css）
  src/case-entities.js    Figma合成实体与关系
  src/views.js            全页面与弹窗内容
  src/app.js              路由、表单、操作、状态同步
  src/styles.css          Figma适配、浅深主题、响应式
  assets/figma/           原始SVG及来源manifest
  tests/                  E2E、专项回归、渲染冒烟
```

UI组件、页面、行为和模拟状态分开；无外部字体/CDN/运行时网络请求。哈希路由不依赖服务端业务API。localStorage键为`ypa-prototype-v1`；跨窗口监听storage同步，但不是生产级多端一致性机制。

## 测试

先启动服务。自动化需要Playwright和系统Chrome，**它们不是原型运行依赖**。测试优先加载本地`playwright`，未安装则尝试本机Codex bundled依赖。默认Chrome通道，可用`PW_CHANNEL`覆盖；自定义端口用`PROTOTYPE_URL`。

```sh
cd prototype
npm test
npm run test:regression
npm run test:smoke
npm run test:case-workflow
npm run test:global-situation
```

```sh
NODE="$HOME/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node"
"$NODE" tests/e2e.mjs
"$NODE" tests/regression.mjs
"$NODE" tests/smoke.mjs
```

## 模拟边界与交付材料

原型不接IDAAS/EasyGateway、RPA、模型服务、Doris、SSE、对象存储、案件系统；角色拦截、审批、SQL检查与审计均为本地演示，不是安全能力承诺。

- 全域态势按时间、行政区、案件/警情、类型与手段重算确定性合成指标，不能用作真实警务结论；警情问答中的3条明细仍不代表完整184条样本。
- 文件仅TXT/CSV/JSON≤2MB，无PDF/OCR/恶意文件扫描；不要上传真实材料。
- 人员轨迹以表替代地图，不真实定位；关系/冲突/异常仅作为待核验线索。
- 报告TXT/JSON、交易CSV，非签章文书；没有自动定罪、冻结或正式合并案件。
- localStorage不是安全数据库。关闭展示偏好只不保存主题和紧凑显示，业务模拟数据仍保留。
- 全量映射不等于PRD全部生产验收通过；R2/R3为预览范围。

逐页覆盖清单、验收截图和全量 PRD 属于内部交付材料，不纳入公开仓库。
