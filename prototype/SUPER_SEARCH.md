## 2. 新增/重构的组件

依照现有无框架工程，采用独立渲染函数而非引入新框架：
- Query 历史切换、用户问题、任务计划、子任务依赖/状态、就地权限卡。
- 阶段性/最终结论、最终报告入口、三条追问建议、会话输入区。
- 权限批量处理、Agent 卡、子任务工具分组、Tool Row、参数/执行记录/代码/结果/产物详情。
- 用户上传目录、Query 目录、文件行及格式预览。
- 实体关系画布、实体详情、关系列表和来源链。

## 3. 重构的数据结构

```text
superSearchSessions[sessionId]
  version: 2
  queries[]
    query: id / originalQuery / rewrittenTaskName / createdAt / status
           subtasks[] / finalConclusion / finalArtifacts / recommendedQueries
    agents[]: assignedSubtasks / toolCalls[]
    permissions[]: permissionCode / relatedSubtaskIds / relatedToolCallIds
    outputs[]: 待发布的产物定义
    graphSeed: 本轮来源实体/关系
  activeQueryId
  artifacts[]: 会话资产（包括上传、各轮产物）
  entities[] / relations[]: 会话累积图谱
  ui / draft / graph
```

`query / agents / permissions` 为当前 Query 的兼容引用，每次读取由 activeQueryId 重新解析，避免刷新后的序列化引用失配。不同查询的工具、子任务、权限、产物 ID 独立；来源链始终保留 Query → SubTask → Tool → Artifact。实体按类型和稳定标识合并，关系按两端和关系类型合并，追加而不是覆盖来源。

现有新建搜索入口的原始问题会被保留；新会话不会带入默认演示的已完成产物。默认 S-0821 保留用户要求的张三合成场景。

## 4. 对话区修改内容

- 原始 Query 与改写后的高层任务分开呈现。
- 五个子任务展示依赖、完成状态和聚合进度；点击定位执行工具。
- 受限子任务下显示权限卡；技术代码折叠到详情，不把日志放进结论。
- 完成前只展示阶段性结果，不提前生成最终文件。
- 完成后展示最终结论与报告入口；始终提供三条可填入输入框的追问建议。
- 多轮 Query 可切换，草稿、阅读位置与焦点保留；输入支持 Enter/Shift+Enter/中文组合态。
- 空来源结果会传递数据缺口，阻止下游生成看似完整的统计和关系结论，最终给出缺口报告。

## 5. 工作空间修改内容

仅保留两个职责明确的 Agent：
- 信息获取 Agent：档案、开户、流水、第三方平台主体查询。
- 数据分析 Agent：解析、标准化、收支统计、关系分析、报告生成。

工具按分配的子任务分组，默认折叠，不重复向两个 Agent 分配同一工具。展开后包含参数、执行记录或带行号/高亮的代码、结果、文件与技术详情。支持运行工具暂停、恢复及失败重试。代码仅为示例展示，不在浏览器执行 Python。

## 6. 文档空间修改内容

- 顶层先为用户上传目录，再按真实 Query 建立独立目录；目录名称使用改写后的任务名。
- 未完成的报告不混入已生成文件，新增 Query 显示空文件状态。
- 文件行支持预览、定位来源、下载；触屏直接显示操作，键盘焦点也能展开操作。
- XLSX/CSV 表格、JSON 结构化文本、MD/TXT 转义文本、图片预览。
- 生成的 PDF 提供对应内容的报告预览和有效 PDF 下载；生成的 XLSX 为真实 OOXML ZIP，而非更改文本扩展名。
- 上传 XLSX 支持首工作表预览（最多 200 条数据、30 列），支持共享字符串和 inline strings，只读缓存值，不执行公式、宏或外链。
- 上传材料仅存在本地浏览器；原始内容可下载。

## 7. 导图空间修改内容

只显示人员、银行卡、手机号、网络账号等业务实体，不把 Agent、Tool、文件、子任务做成图节点。采用不重叠双列布局，复用已有节点视觉；支持缩放、适配、拖动画布、节点选择、关系悬停高亮与实体来源详情。来源事实与待核验推断使用不同线型。默认完成场景为 6 个实体、5 条关系；跨 Query 同一实体合并来源而不新增重复节点。

## 8. 权限申请联动说明

权限请求按当前 Query 的 permissionCode 聚合去重；一个请求可关联多个工具和子任务。批量入口与子任务内入口操作相同对象，支持选中部分申请、取消、重新申请。

批准后相关工具从检查点恢复，按依赖继续调度，SubTask/Query 状态同步变化；完成的工具不会因刷新重放。dueAt 和状态写入快照，统一 tick 调度，不依赖一次性页面闭包定时器。权限批准是**本地模拟**，未调用真实权限服务。

## 9. Artifact / Entity 跨区域联动

- 工具完成 → 发布其 outputs 到会话文档目录。
- 工具完成 → 提取本轮实体/关系并合并会话图谱来源。
- 文件定位来源 → 选中正确 Query → 切换工作空间 → 展开 Agent/Tool → 滚动并短暂高亮。
- Tool 文件按钮 → 文档对应目录/文件；实体来源按钮 → 对应工具。
- 窄屏来源跳转自动打开研判空间抽屉。
- 授权完成、失败/重试、空结果均使用同一模型，三个空间不是独立的固定演示列表。

## 10. 删除/迁移的旧内容

- 将单轮固定查询改成按会话隔离的多 Query 模型。
- 删除与真实 Query 无关的静态分组、未生成报告占位文件。
- 将调度、权限、文件操作从主应用的大事件表移入超级搜索模块。
- 用有效 XLSX/PDF/ZIP 替代仅将文本下载为对应扩展名的行为。
- 用检查点调度替代刷新即丢失的授权回调定时器。
- 重排图谱节点避免重叠；修复来源定位、滚动和焦点恢复。
- 保持任务摘要/最终结论在中间；工具参数、代码、执行记录只在工作空间。

## 12. 限制与待接后端

1. 全部是合成场景。任意新问题仍用张三模板演示，非真实 LLM 改写/规划或调查；输入区和发送提示均明示该边界。
2. 真实鉴权、审批、RPA/数据库/Python 执行、可靠服务端调度、服务端审计与实时消息需后端接入。
3. 上传的任意 PDF/ZIP 暂不做内嵌内容解析，可保留原文件并下载；生成报告已有预览。没有修改全站 CSP 或引入外部 PDF 执行资源。
4. PDF 导出采用中文画布栅格，保证当前浏览器字体显示，文本不可选取；生产需替换为嵌入字体的正式文档生成服务。
5. 上传单文件 1 MB、累计本地数据受 localStorage 限制；XLSX 解压大小限制 5 MB，超限或异常时保留原件并显示限制。不是大文件处理方案。
6. 表格只含少量示例行，演示数值与“2,341 条”是场景元数据，不代表下载了完整业务记录。文件大小标签沿用示例值，不是动态字节计数。
7. 旧超级搜索 v1 页面私有状态会初始化为 v2 演示状态；不迁移旧审批过程，不修改其他页面的快照。需要生产数据迁移策略后再接真实存储。
8. 图谱为稳定双列布局，不是任意规模的力导向/路径分析引擎。
9. 左侧原有静态进度汇总因用户限定正文修改未改动；正文实时进度来自新模型。
10. 旧 PG05 端到端脚本的 6 个未通过用例需后续按新产品交互迁移。未部署到远端。
